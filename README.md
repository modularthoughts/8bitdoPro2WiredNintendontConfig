# wii_8bitdo_wired_pro_2_config
8bitdo Wired Pro 2 INI file for Nintendont.

How to use:

- Put 2DC8_3010.ini inside SDCard/controllers/.
- Open Nintendont.
- Pro 2 must be in D-Input mode (plug in while holding B).
- Play.


Notice:

- No rumble.
- Profile button → Exit/return to loader.
- L1 = R1 → Z.
- Select = L3 = R3 = P1 = P2 = Star = Home → NOTHING.
